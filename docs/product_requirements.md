# Product Requirements

Проект решает задачу оцифровки бумажных анкет гостей в сети ресторанов и предоставляет внутренний интерфейс для ввода данных и формирования отчётов.

На текущем этапе продукт реализован как Telegram-бот для сотрудников.

## Цель MVP

Сделать рабочий внутренний инструмент, который позволяет:

- быстро переносить бумажные анкеты в цифровой вид;
- хранить анкеты централизованно в PostgreSQL;
- получать отчёты по отдельному кафе и по сети;
- экспортировать отчёты в Excel;
- агрегировать и кратко анализировать текстовые комментарии гостей.

## Пользователи системы

### Manager

Использует бота для:

- ввода анкет;
- получения отчёта по своему кафе.

### Superuser

Использует бота для:

- просмотра отчётов по любому кафе;
- просмотра отчётов по сети;
- административных сценариев.

## Состав анкеты

Каждая анкета содержит:

- дату и время визита;
- номер стола;
- 4 yes/no вопроса;
- необязательный комментарий.

## Правила подсчёта

- `Да = 1`
- `Нет = 0`
- итоговый балл = сумма 4 ответов
- итоговый процент:
  - `4/4 = 100%`
  - `3/4 = 75%`
  - `2/4 = 50%`
  - `1/4 = 25%`
  - `0/4 = 0%`

## Отчёты

Система должна уметь строить:

- отчёт по кафе за период;
- отчёт по всей сети за период.

Каждый отчёт должен включать:

- количество анкет;
- средний балл;
- средний процент;
- статистику по каждому вопросу;
- распределение по итоговым оценкам.

Для отчёта по кафе дополнительно доступны:

- сравнение с предыдущим периодом такой же длины;
- список комментариев;
- AI-summary по комментариям.

## Ограничения MVP

В MVP не входят:

- guest-facing web interface;
- автоматический сбор анкет от гостей;
- antifraud-механизмы;
- развитая BI-визуализация;
- сложная ролевая модель;
- полноценная админ-панель.

## Критерий готовности MVP

MVP считается состоявшимся, если:

- менеджер может стабильно вносить анкеты;
- данные сохраняются в PostgreSQL;
- суперпользователь и менеджер могут получать отчёты;
- отчёты корректно считаются по бизнес-правилам;
- Excel-файлы успешно формируются и отправляются через Telegram.
